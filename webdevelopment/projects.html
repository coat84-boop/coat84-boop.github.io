Web Development

Project Description

This project focuses on the development of a professional portfolio website using HTML and CSS. Through my graduate coursework, I have explored fundamental web development concepts, including semantic HTML, responsive design, accessibility, and user-centered development practices. The website consists of five interconnected pages that showcase my professional background, educational experiences, technical projects, and personal reflections.

Throughout development, I have implemented CSS Flexbox, Grid layouts, media queries, responsive navigation, interactive elements, and custom styling. I have also incorporated multimedia content, accessible navigation, structured tables, and visual enhancements to improve the overall user experience. The portfolio continues to evolve as I apply new techniques and refine my understanding of web design.

Personal Reflection

Developing this portfolio has helped me better understand the relationship between technical functionality and effective design. I have learned that creating a website involves more than simply writing code; it requires considering how users interact with information. Each new assignment provides an opportunity to improve the site while strengthening my confidence in HTML, CSS, and responsive development.

02

Instructional Design

Project Description

This instructional design project focuses on developing an accessible learning experience that introduces students to Virtual Local Area Networks (VLANs). The project was created to demonstrate how multimedia, structured instruction, and practical examples can simplify complex networking concepts. The learning environment introduces foundational networking terminology and explains how VLANs are used to logically separate network traffic within an organization.

The instructional website incorporates visual examples, multimedia presentations, organized learning objectives, and assessment activities designed to reinforce understanding. The project also explores the use of analogies and experiential learning to connect unfamiliar technical concepts with recognizable real-world situations. By combining technical accuracy with thoughtful instructional design, the project demonstrates how educational technology can support learners with different levels of prior knowledge.

Personal Reflection

This project reinforced my belief that effective instruction begins with understanding the learner. Technical knowledge alone does not guarantee that information will be understood or retained. I found value in translating complicated networking concepts into relatable examples and structured learning experiences. The process strengthened my interest in instructional design and the role of technology in improving learning outcomes.

IT Leadership

Project Description

My experience in information technology leadership reflects a combination of technical expertise, organizational management, and a commitment to improving how technology supports people. Throughout my professional career, I have worked in systems administration, technical instruction, cybersecurity, and operational support environments. These experiences have provided opportunities to identify technical challenges, develop solutions, and improve organizational processes.

My approach to IT leadership emphasizes communication, collaboration, documentation, and continuous improvement. This includes evaluating existing workflows, identifying inefficiencies, developing training resources, and supporting technology initiatives that align with organizational objectives. I believe successful technology leadership requires understanding both the technical environment and the people who depend on it. By combining technical knowledge with practical leadership principles, I aim to create sustainable improvements that benefit individuals and organizations.

Personal Reflection

My professional experiences have taught me that leadership is not defined solely by technical knowledge or positional authority. Effective leaders must understand the needs of their teams, communicate expectations clearly, and create opportunities for improvement. I have learned that technology is most valuable when it serves people effectively. This perspective continues to influence my professional development and leadership philosophy.
