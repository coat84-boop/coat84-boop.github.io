The "style.css" document logically feels similar to creating network profiles. Instead of customizing each element, I apply the "class" identifier to an element, which points at my "style.css", and formats accordingly. I can do this on a network device as well, for segments that need the same parameters. This way, more than one element/profile can receive the same formatting.

Having a rule set for each class allows me to individulaize the style of each element, without affecting the other elemetns.
